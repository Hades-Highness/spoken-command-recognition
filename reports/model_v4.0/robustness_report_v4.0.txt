NOTES
--------------------------------------------------------------------
* Top-1 Accuracy is the raw argmax over every command clip and is
  threshold-independent, i.e. the same figure as 'Top-1 Accuracy
  (35 Commands)' in report_v4.0.txt.
* Rejection Rate is the share of command clips whose temperature-scaled
  top-1 confidence falls below tau and is therefore served as '_unknown_'.
* Accepted Accuracy covers only answered clips; Correct Yield is answered
  and correct over all clips, the fraction a user sees handled correctly.
* Every row re-uses the same clean clips and every model receives the same
  mixture, so a model-to-model delta is a property of the weights.
* The bank never reads SpeechCommandsDataset.noise_bank: ambient noise comes
  from the held-out _background_noise_ recordings, speech noise from
  held-out LibriSpeech splits, so no evaluated mixture was ever trained on.
